# Soft UI Dashboard assets

Source: the user-provided `soft-ui-dashboard-main.zip`, Soft UI Dashboard 3 v1.1.0
by Creative Tim, distributed under the [MIT license](LICENSE).

`rocket-white.png`, `ivancik.jpg` and `white-curved.jpg` are original template
assets. `../soft-ui.css` adapts its layout, typography, colors, gradients, shadows
and controls to Streamlit. The application uses the ПочтаТех blue-and-white palette (`#294DA6`)
and its logo from `../logo_pochtatex.png`. Semantic risk colors are preserved.

The template's analytics, CDN JavaScript and example account/billing screens are
not part of the application. The existing planning backend supplies the dashboard.
