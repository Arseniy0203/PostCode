# Схема Alert

Ответственный: Человек 2 (recalculation + risk)

| Поле              | Тип                                   | Описание                                                                 |
|-------------------|-----------------------------------------|---------------------------------------------------------------------|
| type              | Literal["red", "yellow", "orange"]      | Тип алерта: red — срыв квартала, yellow — каскад зависимостей, orange — дефицит ресурса |
| task_id           | str                                     | Задача, породившая алерт                                             |
| prodf_id_at_risk  | str                                     | PRODF-цель, находящаяся под риском (обязательное поле для всех алертов) |
| description       | str                                     | Человекочитаемое описание причины и сути риска                       |
| sprint_detected   | int                                     | Номер спринта, на котором алерт был обнаружен                        |

## Правила генерации (см. `backend/risk/alerts.py`)

- **red** — прогнозируемое завершение задачи выходит за неделю 12 (конец квартала).
- **yellow** — сдвиг задачи вызывает сдвиг в цепочке `depends_on`.
- **orange** — на следующий спринт прогнозируется дефицит часов по роли.
